Bashtransfer

Relay sicuro per invio file senza persistenza server

Come si usa

  1. Mittente. Dal terminale, sostituisci FILE con il file da inviare:
    curl -T FILE %%BASE%%

    Il comando stampa una tabella con i comandi per il ricevente (curl, wget, aria2c). Lascia aperto il terminale finché il ricevente non ha finito.

  2. Ricevente. Sull'altro computer incolla uno dei comandi ricevuti dal mittente. Il file viene scaricato mentre il mittente lo invia.

Da una pipe, senza file su disco

tar -czf - CARTELLA | curl -N -T - %%BASE%%/CARTELLA.tgz

Il file passa in streaming dal mittente al ricevente: il server non lo salva mai su disco. Ogni link serve un solo ricevente e scade se nessuno lo usa.

Installare gli strumenti

Ne basta uno tra curl, wget e aria2c.

Debian / Ubuntu

sudo apt install curl wget aria2

Fedora / RHEL

sudo dnf install curl wget aria2

Arch / Manjaro

sudo pacman -S curl wget aria2

openSUSE

sudo zypper install curl wget aria2

Alpine

apk add curl wget aria2

macOS (Homebrew)

brew install curl wget aria2

FreeBSD

sudo pkg install curl wget aria2

Windows (winget)

winget install cURL.cURL winget install JernejSimoncic.Wget winget install aria2.aria2

In PowerShell curl è un alias di un altro comando: usa curl.exe.
